# VersaLife landing page

Public introduction to the telemedicine product: what a visit is, what you can do, and how booking works.

Patient app: https://patient.versalifehealth.com  
Doctor app: https://doctor.versalifehealth.com

```bash
npm install
npm run dev
```

Colors follow the patient and doctor apps: royal blue (`oklch` hue 258) and mint `#50c898`.

Hero video: add `public/video/hero.mp4`. Prompts are in `VIDEO-PROMPTS.md`. The page uses the generated still until that file is present.
